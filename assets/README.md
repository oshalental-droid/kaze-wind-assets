# Mascot source asset

Upload **the actual, previously approved social icon** here with exactly this filename:

`kazeo.png`

The file must be the original approved Kazeo mascot, not an independently generated lookalike.

This publicly accessible file must not contain personal metadata, real names, location data, or identifying information.

On upload, the GitHub Actions renderer reads `assets/kazeo.png` and creates eight slide images under `outputs/episode-001/` from `posts/episode-001.json`.

The resulting images are made of the unmodified original artwork plus text and layout elements. This is a template-based image carousel, not eight individually re-drawn manga frames.

Do not add private identity information or source files unrelated to this fictional brand.
